Bars compare occupancy with the shell capacity 2n². Calcium has 2, 8, 8, 2: 4s fills before 3d, so shell 3 is still below its capacity of 18.

Three rules to watch

Aufbau: for these neutral ground states, follow 1s → 2s → 2p → 3s → 3p → 4s.
Hund: in a p subshell, occupy all three equal-energy orbitals with parallel spins before pairing.
Pauli: an orbital holds at most two electrons, with opposite spins.
